# ce-net-proto

The open ce-net capability token: Ed25519-signed, attenuating capability chains that anyone can
verify **offline** with nothing but the token and a root public key.

- Wire-compatible, byte for byte, with `ce-cap` in the `ce` repo (`tests/compat.rs` proves it both ways).
- Dependencies: `serde`, `bincode` 1, `ed25519-dalek` 2, `sha2`, `hex`. No RNG, no VRF, no network.
- Format spec for other languages: [`docs/TOKEN-FORMAT.md`](docs/TOKEN-FORMAT.md);
  golden vectors: [`tests/vectors.json`](tests/vectors.json) (generated by `cargo test --test vectors`,
  regenerate with `CE_NET_PROTO_REGEN=1`); an independent Python verifier written from the spec:
  [`docs/reference/ce_cap_verify.py`](docs/reference/ce_cap_verify.py).

## CLI

```
cargo install --path .
ce-cap-verify <chain-hex|-> --root <pubkey-hex> [--now <unix-secs>] \
    [--revoked <issuer-hex>:<nonce>]... [--action <ability>] [--holder <pubkey-hex>]
```

Exit 0 = valid (prints holder, abilities, resource, expiry), 1 = invalid (prints the reason), 2 = usage.
It runs `verify_chain`: everything a node's `authorize` checks except the node-specific resource
match; `--action` and `--holder` add the leaf checks.

## Tests

`cargo test` runs the ported ce-cap unit tests, the cross-implementation tests (needs `../ce`
checked out next to this repo, dev-dependency only), the vector tests and the CLI tests.
